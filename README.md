# Patice

A standalone practice mod for SDEZ. Practice predefined chart segments with autoplay previews, adjustable playback speed, and single-run or looping playback.

- `src/` — Mod source code.
- `assets/` — UI assets.
- `segments/` — Segment data format and examples.
- `.github/` — Build and release workflows.

Thanks to [AquaMai](https://github.com/MuNET-OSS/AquaMai) for providing a reference for this project.
