# Patice

A standalone practice mod for SDEZ. Practice predefined chart segments with autoplay previews, adjustable playback speed, and single-run or looping playback.

- `src/` — Mod source code.
- `segments/` — Built-in segment JSON files and their schema.
- `generators/` — Compiles segment data into the mod.
- `.github/` — Build and release workflows.

## Usage

Share this project with your AI agent, such as DeepSeek, GPT, or Claude, and ask it to install the DLL from [Releases](https://github.com/Yeuoly/patice/releases) into your game.

```text
Hey, please help me install Patice into my SDEZ game. Check the project at https://github.com/Yeuoly/patice and download Patice.dll from the latest release.
```
