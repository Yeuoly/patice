# Patice

A standalone practice mod for SDEZ. Practice predefined chart segments with autoplay previews, adjustable playback speed, and single-run or looping playback.

- `src/` — Mod source code.
- `assets/` — UI assets.
- `segments/` — Segment data format and examples.
- `.github/` — Build and release workflows.

Built with [MelonLoader](https://github.com/LavaGang/MelonLoader), [Harmony](https://github.com/pardeike/Harmony), [Unity](https://unity.com/), and [TextMesh Pro](https://docs.unity3d.com/Packages/com.unity.textmeshpro@3.0/manual/index.html), targeting [.NET Framework](https://dotnet.microsoft.com/en-us/download/dotnet-framework).

Thanks to [AquaMai](https://github.com/MuNET-OSS/AquaMai) for providing a reference for this project.
